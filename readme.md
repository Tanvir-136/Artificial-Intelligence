# Artificial Intelligence

## Overview
This repository contains Python implementations of algorithms and problems from "Artificial Intelligence: A Modern Approach" by Stuart Russell and Peter Norvig.

## Contents
Covered chapters:
- Chapter 3: Solving Problems by Searching
- Chapter 4: Search in Complex Environments
- Chapter 7: Logical Agents
- Chapter 13: Uncertainty
- Chapter 18: Learning from Examples
- Chapter 22: Natural Language Processing

## Getting Started

### Prerequisites
- Python 3.8 or higher

## Usage
Refer to individual chapter directories for specific problem implementations and usage instructions.
